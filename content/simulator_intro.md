# Interactive memristor simulator

Move a slider, or type an exact value, and the current–voltage hysteresis is **re-simulated** with the deterministic model. The simulation uses the Python code itself, running in your browser; no curve is interpolated or pre-computed.

Two models are shown:
- **Empirical**, with manually fitted parameters.
- **Ab initio**, with first-principles activation energies.

Both are compared with the experimental data. Every slider starts at the value used in the original code (↺ resets it). Units marked "—" are still to be added. The equations are on the [Model & Equations](#model) page.
